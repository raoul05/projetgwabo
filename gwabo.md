# GWABO — Project Development Instructions

## Overview

GWABO is a modern African ecommerce platform based in Bouaké, Côte d’Ivoire.

The platform allows customers to order fresh food products online with fast local delivery.

The project was initially generated using V0.dev and must now be professionally continued and improved.

The objective is to build a scalable production-ready ecommerce system adapted to African mobile-first users.
